## About

이 블로그는 컴퓨터 그래픽스과 알고리즘을 통한 시각 표현 공부를 위한 글 모음집입니다. 코드로 형태와 움직임을 만들고, 새로운 시각적 표현을 가능하게 해주는 Creative Coding과 Generative Art를 배우는 것이 목적입니다.  

이 블로그에서는 수학 알고리즘을 활용해 아래의 시각 실험을 하고 있습니다.

- WebGL과 OpenGL에서 GLSL을 활용한 Shader Art 실험
- 웹 & 네이티브 환경에서 알고리즘 아트 구현
- Blender에서 OSL을 활용한 Procedural Shader 제작 실험
- Blender에서 Python API를 이용한 모션 그래픽 실험
- Rhino와 Grasshopper에서 Python API를 이용한 추상적 기하 모델 생성 실험
- Unity에서 코드를 사용한 파티클 시뮬레이션 실험


코드의 대부분은 AI를 통해 작성되었으며, 소프트웨어와 라이브러리에서 직접 실행한 내용을 담았습니다.

아래는 이 블로그에서 다루는 그래픽 소프트웨어와 라이브러리의 목록입니다.
---

## Graphic Softwares
자체 API로 스크립팅이 가능한 그래픽 소프트웨어를 다룹니다.

- Cavarly : 2D 벡터 그래픽 및 애니메이션. JavaScript 스크립팅.

- Blender : 3D 모델링, 애니메이션, 셰이더 제작. Python 스크립팅.

- Rhino & Grasshopper : 3D 모델링, Procedural & Parametric Design. Python 스크립팅.  

- Unity : 2D/3D 게임 엔진. Generative Art의 도구로 활용. C# 스크립팅.
