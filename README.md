# BamgasiJM BLOG

Google Drive의 Markdown을 읽고 Cloudflare Pages에 정적 사이트로 배포하는 개인 블로그입니다. 현재 화면·트리·편집 프리뷰를 유지하며, 공개 사이트는 로컬 서버나 DB 없이 동작합니다. 로그인·원본 쓰기 등 관리자 기능은 후속 범위입니다.

## 배포

Drive 동기화 완료 후 `npm.cmd run build`로 배포 파일을 만들고 `npm.cmd run preview`로 http://localhost:3001 에서 확인합니다. 최초 `npm.cmd run cf:login`, `npm.cmd run cf:create` 후 `npm.cmd run deploy`로 배포합니다. 지정 폴더의 Markdown은 기본적으로 모두 공개 대상입니다. `published: false` 또는 `draft: true` frontmatter가 있는 글은 빌드에서 제외합니다.

[Cloudflare 최초 배포와 글 갱신 안내](docs/cloudflare-deployment.md)를 먼저 확인하세요. Google Drive 자체에서 호스팅하는 방식은 아니며, 수정 후 재배포해야 반영됩니다.

## 로컬 개발 실행

필요한 설치는 **[Node.js 24 LTS 이상](https://nodejs.org/)** 하나입니다. Chrome, Edge, Firefox 등 최신 브라우저를 사용하세요. 현재 작업 환경에서는 Node.js v24.11.0과 npm 11.6.1을 확인했습니다.

설치 후 새 PowerShell 터미널을 열고 실행합니다.

```powershell
Set-Location C:\Works\Dev\Blog
node --version
npm --version
npm ci
npm run dev
```

브라우저 주소창에 **http://localhost:3000**을 입력하세요. 터미널은 실행한 상태로 두고, 종료할 때 **Ctrl+C**를 누릅니다. 처음에는 `npm ci`로 KaTeX 의존성을 설치합니다. pnpm과 DB 설정은 필요하지 않습니다. Google Drive 데스크톱 앱이 연결한 폴더를 읽으며 Cloud·API 키 설정은 필요하지 않습니다. KaTeX와 수식 폰트는 로컬 서버에서 제공합니다.

PowerShell에서 `npm.ps1` 실행 정책 오류가 발생하면 다음 명령으로 실행할 수 있습니다.

```powershell
npm.cmd run dev
```

3000번 포트를 이미 사용 중이면:

```powershell
$env:PORT = '3001'
npm.cmd run dev
```

이때 주소는 **http://localhost:3001**입니다. 다른 실행 환경에서 `localhost` 연결에 문제가 있으면 같은 포트의 `http://127.0.0.1:3000`을 사용할 수 있습니다. 로컬 PC에서 확인하는 서버이므로 인터넷에 공개되지는 않습니다.

## 둘러볼 수 있는 화면

- 첫 화면: 소개 페이지. `BamgasiJM` 로고 또는 왼쪽 `Introduction`을 눌러 다시 열 수 있습니다.
- 왼쪽: 실제 Markdown 폴더·파일 트리, 폴더·글 제목 검색, 독립 스크롤. 검색 시 일치하는 항목의 경로가 펼쳐집니다. 새 초안 버튼은 편집할 때 표시합니다.
- 검색 아래 **아이콘 토글 버튼 하나**로 전체 열기·접기를 전환하여 중첩 폴더를 한 번에 조작합니다. 검색 중 전체 접기를 누르면 검색도 해제합니다.
- 가운데: 글 제목과 본문, 코드 블록·이미지·표.
- 오른쪽: 현재 글의 소제목으로 이동하는 목차. 작은 화면에서는 접힙니다.
- 왼쪽 목록의 오른쪽 경계와 목차의 왼쪽 경계를 **드래그**해 너비를 조절할 수 있습니다. 구분선에 포커스를 두고 좌우 방향키로도 조절하며, Shift는 크게 이동, Home/End는 최소·최대 너비, 더블클릭은 기본 너비 복원입니다. 조절한 너비는 브라우저에 저장됩니다.
- 상단 **Edit / Read**: 좌측 Markdown 입력, 우측 프리뷰, 블록 기준 양방향 스크롤 동기화, 패널 너비 조절. 경계에 포커스를 두고 좌우 방향키로도 조절할 수 있습니다.
- 코드 입력 중 프리뷰를 다시 그려도 에디터 위치가 밀리지 않도록 사용자 조작과 자동 스크롤을 구분합니다. 프리뷰를 직접 휠·키보드로 탐색할 때는 반대쪽 동기화가 동작합니다.
- **Drive 미디어**: JPG·PNG·GIF·MP4·PDF의 표시 방식과 삽입 흐름 예시.
- **초안 저장**: 기존 샘플 글의 원문을 현재 브라우저 localStorage에 보관합니다. 읽기 화면의 공개 샘플과 분리됩니다.
- **발행**: 현재 탭의 읽기 화면에만 반영하는 프로토타입 동작입니다. 새로고침하면 공개 샘플로 돌아오며 실제 온라인 발행은 하지 않습니다.
- 상단 **Light mode / Dark mode**: 테마 전환. 첫 방문은 다크 모드이고 저장한 선택은 유지합니다. 모바일에서는 상단 메뉴로 탐색기를 열고 편집·프리뷰 탭으로 전환합니다.
- 테마 버튼 옆 **Code colors on / off**: 예약어·변수·함수·문자열·숫자·주석 등의 색상 구분 또는 단색 표시. 읽기와 프리뷰에 함께 적용하고 선택을 브라우저에 저장합니다.

블로그 제목과 소유자 닉네임은 `BamgasiJM`입니다. 배경은 라이트·다크 모두 무채색이며 링크·선택 글자 등에 민트색을 사용합니다. 글과 탐색에 집중하도록 슬로건, 장식 라벨, 개발 상태 배너, 태그·시리즈 카드와 임의의 대표 이미지를 제거했습니다. 구현 상태 설명은 화면 대신 이 문서에서 관리합니다.

본문 폰트는 **Noto Sans / Noto Sans KR**, 코드 영문은 **JetBrains Mono**, 코드의 한글은 **Nanum Gothic Coding**입니다. Google Fonts에서 불러오므로 별도 폰트 설치는 필요하지 않습니다. 인터넷 연결이 없으면 브라우저의 sans-serif·monospace 대체 글꼴로 표시됩니다.

## Google Drive 연결

기본 원본은 **G:\내 드라이브\BamgasiJM_Velog_MD**입니다. Google Drive 데스크톱 앱을 실행한 상태에서 서버를 켜면 하위 Markdown을 읽기 전용으로 표시합니다. 폴더를 공개하거나 Google Cloud·API 키·결제 계정을 설정할 필요가 없습니다. 브라우저 편집은 유지하지만 Drive 원본에는 쓰지 않습니다.

[폴더 설정과 실행 방법](docs/google-drive-setup.md)을 참고하세요. 이 경로는 내 PC에서만 접근할 수 있습니다. 외부 호스팅에는 `npm run deploy`가 동기화된 글을 정적 배포 파일로 만들어 업로드합니다.

## 소개와 글 파일 위치

소개 페이지는 **`web/introduction.md`**에서 수정합니다. 기본 소개는 'BamgasiJM / 크리에이티브 코딩 탐구하는 디자이너'이며 Blender, WebGL, p5.js 등의 기술을 적어두었습니다.

기본 글 목록은 **Drive 데스크톱 앱의 동기화 폴더에 있는 `.md` 파일**을 재귀적으로 읽습니다. 로컬 모드를 선택하면 설정한 다른 폴더의 `.md` 파일을 읽습니다. 기존 프로젝트의 `md` 폴더는 사용하지 않아 삭제했습니다. 폴더·파일명은 자연 정렬하며 본문은 선택할 때 불러옵니다. 파일을 추가·수정한 뒤 브라우저를 새로고침하면 반영됩니다. 파일 확장자는 목록에서 생략하고 본문 제목은 첫 번째 `#` 제목을 사용합니다.

로컬 폴더를 사용하려면 `content.config.json`을 다음처럼 수정합니다. Drive 폴더 변경 방법은 위 연결 문서를 참고하세요.

```json
{
  "source": "local",
  "directory": "C:/Works/MyArticles"
}
```

`directory`에는 프로젝트 기준 상대 경로나 절대 경로를 지정할 수 있습니다. 또는 PowerShell에서 환경변수로 덮어쓸 수 있습니다.

```powershell
$env:BLOG_CONTENT_DIR = 'C:\Works\MyArticles'
npm.cmd run dev
```

위 환경변수는 설정 파일보다 우선합니다. 기본 설정으로 되돌리려면 `Remove-Item Env:BLOG_CONTENT_DIR`를 실행한 뒤 서버를 재시작하세요. 파일 API를 추가한 이번 업데이트도 실행 중인 서버를 Ctrl+C로 종료한 뒤 다시 실행해야 합니다. 예전에 지정한 `PORT=3001`이 남아 있다면 서버가 출력하는 실제 주소로 접속하세요.

이 API는 로컬 디자인 확인용입니다. 선택한 폴더의 Markdown은 모두 탐색 가능하며, 브라우저 편집은 **디스크 원문에 저장되지 않습니다**. 초안은 브라우저에만 저장하고 파일의 실제 수정은 에디터에서 진행하세요. 실제 서비스에서는 발행 상태와 권한을 적용한 DB 연동으로 교체합니다.

## 현재 초안의 한계

실제 인증·DB·Drive 쓰기·파일 업로드는 구현 전입니다. 정적 사이트의 Cloudflare 배포 명령은 제공하지만 실제 계정 로그인과 업로드는 아직 실행하지 않았습니다. Drive 데스크톱 폴더의 Markdown 읽기는 구현되어 있으며 Cloud·API 키가 필요하지 않습니다. 미디어 카드는 자리 표시자입니다. 인라인 `$a>0$`, 블록 `$$...$$` 수식은 KaTeX로 실제 렌더링합니다. 잘못된 수식은 해당 부분에 오류를 표시하고 나머지 본문은 계속 표시합니다. 현재 Markdown 렌더러는 제목·강조·인용·코드·HTTP(S) 이미지·링크·표·가로 구분선·인라인 및 블록 수식을 지원하며 정식 버전에서 CodeMirror와 공통 Markdown 파이프라인을 적용합니다. 코드 색상은 기본 토큰 구분으로, 완전한 언어 분석이나 변수 의미 분석은 아닙니다. 언어가 없거나 지원하지 않는 언어는 단색으로 표시합니다. 트리 구조 편집·드래그 정렬도 정식 구현 범위입니다.

외부 이미지는 `![대체 텍스트](https://example.com/image.jpg)` 형식으로 입력합니다. 표는 아래처럼 머리글 다음에 구분 행이 필요하며, `:---`, `:---:`, `---:`로 왼쪽·가운데·오른쪽 정렬을 지정할 수 있습니다. 넓은 표는 표 영역 안에서 가로 스크롤됩니다.

```markdown
| 항목 | 값 |
| :--- | ---: |
| 반지름 | 10 |
| 높이 | 20 |
```

이미지와 표는 읽기 화면과 편집 프리뷰에서 같은 렌더러를 사용합니다. 외부 이미지는 원본 서버에서 직접 불러오며 Storage에 자동 복사하지 않습니다. Markdown 모듈을 추가한 업데이트를 적용할 때는 실행 중인 서버를 Ctrl+C로 종료한 뒤 `npm.cmd run dev`로 다시 시작하고 브라우저를 새로고침하세요.

새로 만든 글은 새로고침하면 사라집니다. 기존 샘플의 초안 저장도 이 브라우저에 한정되며 다른 기기와 동기화되지 않습니다. 중요한 원문은 별도로 보관하세요. 디자인 데이터를 초기화하려면 브라우저 개발자 도구의 Application/Storage에서 `gyeol-design-preview-v1` 키를 삭제한 뒤 새로고침합니다.

현재 코드의 JavaScript 구문 검사는 다음과 같습니다.

```powershell
npm run check
npm test
```

## 실제 서비스 구현 시 준비할 것

| 도구·계정 | 필요한 시점과 용도 |
| --- | --- |
| Node.js 24 LTS 이상 | 현재 초안과 이후 Next.js 개발 |
| pnpm | 실제 Next.js 프로젝트의 패키지 관리. `npm install --global pnpm` |
| Git | 변경 이력과 배포 저장소 관리. [설치](https://git-scm.com/downloads) |
| Docker Desktop | 로컬 Supabase를 쓸 때. 원격 개발 DB를 쓴다면 선택 사항. [설치](https://www.docker.com/products/docker-desktop/) |
| Supabase CLI | 실제 앱의 migration 및 로컬 DB 관리. 프로젝트 개발 의존성으로 고정 예정 |
| GitHub·Vercel·Supabase 계정 | 저장소, 무료 배포, DB·인증·이미지 저장 |
| Google 계정·Drive 데스크톱 앱 | PC에 연결된 폴더의 Markdown 읽기 |

Docker Desktop을 사용할 경우 Windows의 WSL2와 가상화 설정이 필요할 수 있습니다. 현재 원본 연결은 Drive 데스크톱 앱을 이용하며 OAuth 개발 설정은 필요하지 않습니다.

현재 배포에는 Next.js·Supabase·pnpm을 요구하지 않습니다. 아래의 실제 Next.js 앱 관련 도구는 관리 기능을 확장할 경우의 이전 계획이며 아직 초기화하지 않았습니다. 이후 앱 생성 시 확정된 pnpm 버전, 환경변수 예시, DB migration 명령, OAuth callback과 `pnpm dev` 실행법을 여기에 추가합니다. 현재는 위의 `npm run dev`로 디자인 초안을 확인하면 됩니다.

프로젝트의 최종 요구사항·구현 규칙은 [AGENTS.md](AGENTS.md), 무료 운영 가능성은 [분석 문서](docs/project-feasibility.md)를 참고하세요.

KaTeX 자산 경로가 추가되었으므로 기존 서버를 **Ctrl+C**로 종료하고 `npm.cmd run dev`로 다시 실행한 뒤 **Ctrl+F5**로 새로고침하세요. 검색창 문구는 `Search folders and posts`이며 로고 크기는 기존의 1.5배입니다.

## 블로그와 수업자료 탐색

왼쪽은 로고와 Introduction 아래를 구분선으로 나누어 **Generative Art 블로그**와 **Class 수업자료**를 표시합니다. 기존 md 폴더 트리, 검색, 전체 폴더 토글은 블로그 구획에만 적용됩니다. 두 목록은 각각 스크롤할 수 있습니다.

Class에는 요청한 다섯 수업을 표시하고 수업명을 펼치면 1~15주차 PDF를 본문 전체 크기로 볼 수 있습니다. 수업 PDF URL은 `web/courses.js`의 과목별 `weeks`에서 수정합니다. Drive 원문은 변경하지 않습니다. 주차별 Google Drive PDF는 preview iframe으로 표시합니다.

데스크톱 읽기 화면 상단의 **목차 아이콘**을 누르면 오른쪽 목차를 숨기거나 다시 표시합니다. 목차를 숨기면 본문 영역이 넓어지며, 다시 표시하면 기존 목차 너비로 돌아옵니다. 선택은 브라우저에 저장됩니다. 작은 화면에서는 기존처럼 목차를 자동으로 숨깁니다.

상위 탐색 제목 세 개는 민트색으로 강조합니다. 우상단은 목차·코드 색상·테마·편집 SVG 아이콘만 표시하며, 밝은 회색과 어두운 회색 배경으로 상태를 구분합니다. 편집 전환은 펜, 읽기 전환은 펼친 노트 아이콘이며 버튼에 마우스를 올리면 기능을 확인할 수 있습니다. 사이트 제목은 BamgasiJM BLOG입니다.

블로그 검색창 오른쪽 아이콘은 전체 폴더를 열고 접습니다. Generative Art 블로그와 Class 수업자료 제목 오른쪽의 화살표는 구획 전체를 접고 펼치며 선택은 브라우저에 저장됩니다. 폴더 화살표와 목록 간격은 두 구획에 동일하게 적용하고 사각형 아이콘을 제거했습니다. 로고는 호버해도 색이 바뀌지 않습니다.

파일 정리: 미사용 Drive API 모듈·테스트와 Python/Rhino용 에디터 설정을 제거했습니다. `dist/`는 배포 프리뷰, `node_modules/`는 설치된 실행 도구이므로 유지하며, 기존 `md` 폴더는 사용자 요청으로 삭제했습니다.

## 수업 PDF 주소 변경

[수업 PDF 설정 안내](docs/class-pdf.md)를 참고하세요. `web/courses.js`에 다섯 과목의 1~15주차 주소를 각각 넣을 수 있습니다. 현재는 모두 요청한 동일 PDF를 사용합니다. 일반 Drive 공유 링크를 붙여넣으면 `/preview`로 변환합니다. PDF를 선택하면 전체 본문을 사용하고, 블로그 글에서는 기존 Markdown·편집 기능을 유지합니다. 로컬 개발 서버는 재시작하고 Ctrl+F5로 확인하며, 배포 프리뷰와 공개 사이트는 다시 빌드·배포해야 합니다.

프로덕션 웹 화면 코드는 `web/`에 있습니다. 도구는 `tools/`, 검증 코드는 `tests/`에 두며, 배포 산출물은 기존처럼 `dist/`에 생성합니다. 기존 `prototype/` 경로는 사용하지 않습니다. 폴더 변경 후 개발 서버를 재시작하세요.

Favicon은 루트 `img/`의 ICO·16/32px PNG와 Apple touch icon을 사용하며 개발·배포 모두 포함합니다. 수업자료 아래에는 작은 저작권 푸터가 표시됩니다. 아이콘을 바꾼 뒤에는 재배포하고 브라우저 캐시를 갱신하세요.
